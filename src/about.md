# About drachtio

## Making SIP server applications as easy to build as web apps

Building SIP server applications is harder than it should be. It doesn't leverage web developer skill sets, it often means deploying multiple products for point solutions, and it usually requires mastering esoteric configuration file syntax and directives.

And once you've got all that deployed? Congratulations: you've just bought yourself a full-time job managing it.

drachtio is the open source SIP application server ecosystem that aims to end all that. It consists of a high-performance, easily configured SIP server written in C++, and a Node.js framework that lets applications control the server and implement their logic.

One server runs all of your applications, and a familiar HTTP-style middleware API lets you create any type of SIP server application using Node.js.
